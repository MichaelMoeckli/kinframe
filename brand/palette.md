# Visual system

> Working draft. Refine once the logo and reference board are locked.

## Palette

Warm, paper-feeling neutrals with one quiet accent.

| Token        | Hex       | Use                                    |
| ------------ | --------- | -------------------------------------- |
| `--paper`    | `#FBF7F0` | Page background                        |
| `--ink`      | `#1F1A14` | Body text, headings                    |
| `--ink-soft` | `#4A4239` | Secondary text                         |
| `--frame`    | `#8C6A45` | Accent (CTAs, frame illustrations)     |
| `--frame-dk` | `#5B4530` | Hover state, deep accents              |
| `--cream`    | `#F2E9D8` | Card surfaces, soft dividers           |

## Type

- **Display**: a warm serif (placeholder: Fraunces, EB Garamond, or similar). Lockup TBD.
- **Body**: a quiet humanist sans (placeholder: Inter, or similar).
- Generous line-height. Avoid all-caps. Title case for headings.

## Iconography

Minimal. Hand-drawn / sketched line weight where used. No emoji, no flat tech icons.

## Photography & illustration

- Hero gallery shows real photos beside their painted versions
- The painted version is always the hero, not the photo
- Avoid stock photography entirely
